# Reference material (downloaded 2026-09-04)

- dos-twz-4.22/   Timewave Zero 4.22 for MS-DOS (Peter Meyer, Dolphin Software 1993). From https://archive.org/details/twz_20200405
                  TW_EN.C = fractal transform engine source. DATA.TWZ = 384 data points (Kelley set). VERSIONS.TXT = feature history.
- wen_grph/       WEN_GRPH 2.1 (Meyer 1998): derives the 384 points from any hexagram sequence. From https://archive.org/details/twz_win_4.3
                  KING_WEN.TWZ = Kelley (half-twist), KING_WEN.TWX = Watkins (no twist), SHELIAK.TWX = Sheliak, HUANG_TI.TWZ = Huang Ti (twist).
- tw/             TW.C (Meyer 1998): wave value at a point for all four sets. DATA.TW1..4 = Kelley, Watkins, Sheliak, Huang Ti (no twist).
- papers/         Meyer, "The Mathematics of Timewave Zero" (appendix to The Invisible Landscape, 2nd ed. 1993) with test values
                  t(1)=0.0000036160151, t(9.5)=0.000047385693, t(1e12)=5192046.655436.
                  Watkins, "Autopsy for a Mathematical Hallucination?" (1996). Sheliak, "Re-examination" (1998), 8 segments.
                  2001 third-party user guide to the DOS software (keys, resonance dialogs, sample screens).
- screenshots/    archive.org capture of the 4.22 main screen.
