The attached zip file has all the necessary files for the program to run.  Here are some basic instructions:

1. Put all files in the same directory.
2. Go to the directory and double click Twz87.bat to open the program in a DOS window.
3. Press any key and the program goes to full screen.
4. Press C to set the target date (e.g., 9-11-2001).  Enter after month, day, year.  You can use the arrow keys later to fine-tune the vertical line marker on the graph to a given hour, year, or whatever.
5. Press E to specify timespan: one day, or a million years, or whatever, up to 7 billion years.  
6. Press F to actually display the graph for the time period you have specified.
7. Start again if you like with a different target date.
8. Press Q to quit the program.

The other menu options are more esoteric in terms of "resonances" of the fractals of the wave form as they echo over smaller and larger spans of time.  But these basics are entertaining enough.
